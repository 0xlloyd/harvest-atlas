- **Season data, produce names and regions** (`data/produce.json`, `data/regions.json`, `data/seasons/`, `data/sources/`): [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). Credit "Harvest Atlas" with a link to https://github.com/0xlloyd/harvest-atlas.
- **Producer listings** (`data/producers/`): [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). If you publish an improved copy of the producer data, share it under the same licence.

## What we take from sources

Each season entry records facts: the months a crop is grown and harvested locally, cross-checked across the sources listed in `data/sources/`. We do not copy any source's text, layout or images. Where a source's own licence asks for attribution, the source record names it, and so does every answer from the MCP server.

If you publish a source we cite and want it credited differently or removed, open an issue.
